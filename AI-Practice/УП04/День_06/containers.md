Работа с контейнерами
hello-world
команда: sudo docker run hello-world
результат: Hello from Docker! образ скачался и контейнер завершился
nginx
команда: sudo docker run -d --name up04-web -p 127.0.0.1:8080:80 nginx:alpine
результат: контейнер запустился, curl -I http://127.0.0.1:8080 вернул 200 OK
stop / start: контейнер останавливался и запускался снова, сервис отвечал
Ответы на вопросы
Чем образ отличается от контейнера? образ - шаблон, контейнер - запущенный экземпляр образа
Почему hello-world завершился, а nginx продолжает работать? hello-world просто печатает сообщение и выходит, nginx работает как сервер в фоне
Что означает -d? запуск в фоне
Что означает --name up04-web? задаёт имя контейнера
Зачем нужен порт 8080:80? связываем порт 8080 на хосте с портом 80 внутри контейнера
Почему указан адрес 127.0.0.1? чтобы сервис был доступен только локально на машине
Как увидеть логи контейнера? sudo docker logs up04-web
Чем stop отличается от rm? stop останавливает контейнер, rm удаляет его
