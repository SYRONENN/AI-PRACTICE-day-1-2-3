Паспорт системы

Название и назначение: Консольный ИИ-агент «Помощник по выбору фильмов»,  подбирает фильмы и сериалы по жанру, настроению и предпочтениям пользователя с поддержкой истории диалога.
Модель и поставщик: GigaChat-2 (Сбер)
      
Версии ПО:
Операционная система: Ubuntu Server 24.04.5 LTS (хост и базовый образ контейнера ubuntu:24.04)
Python: 3.12
Docker: 29.10.0
Docker Compose: v5.8.0
      
Состав файлов (AI-Practice/УП01/AI-Agent/):
final_day15.py - основной скрипт запуска консольного агента
prompts.py, structured_output.py, api_errors.py, logging_demo.py - модули промптов, структурированного вывода, обработки ошибок и логирования.
requirements.txt - зависимости Python
Dockerfile, .dockerignore, compose.yaml - конфигурация сборки образа и запуска контейнера
.env.example - шаблон переменных окружения без секретов
certs/Russian_Trusted_Root_CA.cer - корневой сертификат для проверки SSL-соединения
Внешние сервисы: GigaChat API

Требования к сети и ресурсам: Постоянный доступ в интернет, от 512 МБ оперативной памяти, около 500 МБ свободного дискового пространства для образа
      
Расположение конфигурации без секретов: Шаблон переменных хранится в репозитории в файле AI-Practice/УП01/AI-Agent/.env.example. Рабочий файл .env создаётся локально в AI-Practice/УП01/AI-Agent/.env (исключён из Git и образа Docker)
